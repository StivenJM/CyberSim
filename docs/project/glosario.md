# Glosario

| Término | Significado en CyberSim |
|---|---|
| Estudiante | Persona que practica niveles y tiene historial de intentos |
| Profesor / docente | Perfil que organiza cursos y consulta actividad de estudiantes |
| Curso / grupo | Unidad de agrupación con nombre, docente propietario y código de acceso; el código usa `curso` |
| Matrícula | Relación de participación entre estudiante y curso |
| Código único | Identificador numérico del estudiante; diferente al código de invitación |
| Código de acceso / invitación | Cadena para ingresar a un grupo, con vencimiento |
| Escenario / nivel | Ejercicio con contexto, dispositivos, acciones, objetivos y fases |
| Slug | Nombre estable usado para vincular intentos a un escenario, como `tutorial` |
| Fase | Etapa del escenario con objetivos y eventos asociados |
| Objetivo | Resultado que el jugador debe alcanzar para avanzar |
| Evento | Notificación o comprobación programada dentro de la simulación |
| Ataque | Situación simulada que requiere mitigación antes de su ejecución |
| Hardening | Cambios de configuración que reducen exposición de un dispositivo simulado |
| Zona / oficina / espacio | Niveles de organización de la escena y sus dispositivos |
| Activo | Documento, firma, clave u otro contenido representado en un dispositivo |
| Firewall | Reglas simuladas que permiten o bloquean tráfico por red/protocolo/dirección |
| VPN | Perfiles simulados que modelan conectividad protegida entre extremos |
| Intento | Registro enviado al fallar una fase o completar un escenario |
| Progreso | Historial de intentos o resumen de finalización de un escenario |
| Ranking / leaderboard | Comparación de puntos entre estudiantes de un grupo |
| Feedback / retroalimentación | Análisis individual, fortaleza, área de mejora y consejo |
| Análisis de curso | Resumen y sugerencias sobre actividad del grupo |
| Tutor / chat | Asistente conversacional sobre conceptos y contexto de la práctica |
| Modo contexto | Consulta al tutor sobre el objeto/configuración seleccionado |
| Agente malvado | Nombre de la funcionalidad que solicita desafíos dinámicos a una integración externa |
| ECS | Patrón de entidades, componentes y sistemas utilizado para modelar la simulación |
| RAG | Recuperación de conocimiento para enriquecer la pregunta enviada al modelo |
| Embedding | Vector que representa un texto para realizar búsqueda semántica |
| Webhook | Endpoint externo al que la API envía una solicitud de generación |
| ADR | Registro de una decisión, con su contexto, estado y consecuencias |

Para nombres de tablas/contratos consultar [modelo de datos](../architecture/modelo-de-datos.md) y [API](../architecture/api-http.md). Para implicaciones educativas consultar [reglas funcionales](reglas-funcionales.md).
