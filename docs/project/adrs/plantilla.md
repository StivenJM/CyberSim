# ADR NNNN: Título de la decisión

- Estado: Propuesta / aceptada / observada en implementación / sustituida / rechazada.
- Fecha de documentación: AAAA-MM-DD.
- Fecha y evidencia de aprobación: completar solo si consta.
- Alcance: módulos y comportamiento afectados.
- Relación: ADR previo o sucesor, si aplica.

## Contexto

Problema concreto, necesidades y restricciones verificables. Distinguir hechos del código, requerimientos del usuario y supuestos pendientes.

## Decisión

Opción elegida o propuesta y sus límites. Si es retrospectiva, declarar que la motivación histórica no está acreditada.

## Consecuencias

Beneficios, costos, riesgos y trabajo que exige. Indicar efectos para usuarios, datos y operación cuando corresponda.

## Alternativas

Opciones relevantes y tradeoffs. No atribuir deliberaciones históricas que no están documentadas.

## Evidencia y validación

Enlaces a código, especificación o aprobación. Qué prueba demuestra la implementación y qué falta validar. Si es propuesta, criterios verificables para considerarla implementada.
